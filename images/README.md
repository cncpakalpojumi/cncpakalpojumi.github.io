# Attēlu vietturi

Šajā mapē klients vēlāk pievienos reālus foto no ražošanas.
Kamēr foto nav pieejami, HTML kodā tiek izmantoti vietturi ar komentāru
`<!-- TODO: aizvietot ar reālu foto no ražošanas -->`.

Ieteicamie failu nosaukumi (aprakstoši, SEO draudzīgi):

```
cnc-frezesana-workshop.jpg          # galvenā iekārta darbnīcā
cnc-wattsan-1300x2500.jpg           # Wattsan 3 asu frēze
cnc-koka-detala-frezesana.jpg       # koka/MDF apstrāde
cnc-akrila-detala.jpg               # akrila/plastmasas apstrāde

cnc-darbnica-process.jpg            # process / darbnīca
portfolio/koka-mebelu-paneli.jpg    # portfolio: koka mēbeļu paneļi
portfolio/reklamas-burti-akrils.jpg # portfolio: reklāmas burti
portfolio/aluminija-plaksnes.jpg    # portfolio: alumīnija plāksnes
portfolio/dekorativie-paneli.jpg    # portfolio: dekoratīvie paneļi
```

Prasības attēliem:
- Reāli foto (nevis stock / 3D render).
- Optimizēti web izmēram (JPG/WebP, ~100–250 KB).
- Alt teksts latviešu valodā katram attēlam.
