# SVG ikonas

Viena konsekventa, minimāla līnijveida ikonu kopa (Feather/Lucide stila).
Ikonas tiek ievietotas tieši HTML kā inline SVG, lai:
- nebūtu papildu HTTP pieprasījumu;
- varētu krāsot caur CSS (`fill="none" stroke="currentColor"`).

Izmantotās ikonas:
- `layers` / `tree` — koks/MDF/saplāksnis
- `box` / `layers` — plastmasa/akrils/kompozīti
- `settings` / `cog` — alumīnijs/metāli
- `file` / `upload` — faila augšupielāde
- `clock` — izpildes laiks
- `phone`, `mail`, `map-pin` — kontakti
- `menu`, `x` — mobilā izvēlne
